**Goal:** Ein lauffähiges, append-only Event-Log mit Hash-Kette, Idempotenz und Einheiten-Zerlegung, bedienbar über eine Befehlszeile.

**Architecture:** `core` rechnet Hashes und Ketten und kennt keine Datenbank; `storage` kennt SQL und keine Domäne; `contract` enthält nur Typen. ## Review Focus

Fünf Eingabeklassen, die das Spec nicht behandelt, deren Verhalten aber einen Benutzer beißen würde. Für jede ist unten in der zuständigen Aufgabe ein Test eingeplant.

1. **Nullbyte im Text** (`\u0000`) — PostgreSQL `jsonb` kann es nicht speichern. Ein eingeworfener Text mit Nullbyte muss mit klarer Meldung abgelehnt werden, nicht mit einem Datenbankfehler aus der Tiefe. → Aufgabe 2
2. **Leerer oder nur aus Leerraum bestehender Text** — die Zerlegung würde null Einheiten ergeben. Ein Event ohne Einheiten ist sinnlos; der Einwurf muss abgelehnt werden. → Aufgabe 4
3. **Naiver Zeitstempel von der Befehlszeile** — `--occurred-at 2026-05-01T10:00:00` ohne Zone würde stillschweigend als Ortszeit gelesen und als UTC gehasht, also chronologisch falsch einsortiert. Muss abgelehnt werden. → Aufgabe 9
4. **Ganze Zahl außerhalb des sicheren Bereichs** — jenseits ±(2⁵³−1) ist die Zahl in anderen Sprachen nicht verlustfrei darstellbar, der Hash also nicht reproduzierbar. Muss abgelehnt werden. → Aufgabe 2
5. **Unbegrenzt großer Text** — ein 100-MB-Einwurf würde Speicher und Transaktion sprengen. Es braucht eine Obergrenze mit klarer Meldung. → Aufgabe 9

```python
# Previously — append-only Wissensspeicher für Projektverläufe
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Kanonisierung von Nutzlasten nach RFC 8785, für einen eingeschränkten Bereich.

Der zulässige Bereich ist absichtlich klein (§3.2 des 1a-Specs): keine
Gleitkommazahlen, Schlüssel nur ASCII-Kleinschreibung, ganze Zahlen nur im
sicheren Bereich. Dadurch ist `json.dumps` mit festen Flaggen bereits
JCS-konform und es braucht keine Fremdbibliothek:

- `sort_keys=True` sortiert nach Codepunkt; bei ASCII-Schlüsseln ist das
  dieselbe Ordnung wie JCS' Sortierung nach UTF-16-Codeeinheiten
- `separators=(",", ":")` entfernt jeden Leerraum
- `ensure_ascii=False` liefert die von JCS verlangte UTF-8-Darstellung mit
  Minimal-Escaping
- ohne Gleitkommazahlen entfällt die sprachabhängige Zahlendarstellung, die
  der schwierigste Teil jeder Kanonisierung ist
"""

import json
import re
from collections.abc import Mapping, Sequence

from previously.core.errors import InvalidPayload


MAX_SAFE_INT = 2**53 - 1
KEY_PATTERN = re.compile(r"^[a-z][a-z0-9_]*$")


def _pruefen(wert: object, pfad: str) -> None:
    if wert is None or isinstance(wert, bool):
        return
    if isinstance(wert, int):
        if abs(wert) > MAX_SAFE_INT:
            raise InvalidPayload(
                f"{pfad}: ganze Zahl außerhalb des sicheren Bereichs "
                f"(±{MAX_SAFE_INT}) — nicht sprachübergreifend exakt"
            )
        return
    if isinstance(wert, float):
        raise InvalidPayload(
            f"{pfad}: Gleitkommazahl nicht erlaubt — Maßstab als ganze Zahl "
            "angeben (§3.2)"
        )
    if isinstance(wert, str):
        if "\x00" in wert:
            raise InvalidPayload(
                f"{pfad}: Nullbyte nicht erlaubt — PostgreSQL jsonb kann es "
                "nicht speichern"
            )
        return
    if isinstance(wert, Mapping):
        for schluessel, unterwert in wert.items():
            if not isinstance(schluessel, str) or not KEY_PATTERN.match(schluessel):
                raise InvalidPayload(
                    f"{pfad}: Schlüssel {schluessel!r} muss auf "
                    f"{KEY_PATTERN.pattern} passen"
                )
            _pruefen(unterwert, f"{pfad}.{schluessel}")
        return
    if isinstance(wert, Sequence):
        for i, unterwert in enumerate(wert):
            _pruefen(unterwert, f"{pfad}[{i}]")
        return
    raise InvalidPayload(f"{pfad}: Typ {type(wert).__name__} nicht erlaubt")


def canonical(payload: Mapping[str, object]) -> bytes:
    """Kanonische JCS-Bytes der Nutzlast. Wirft `InvalidPayload`."""
    _pruefen(payload, "$")
    text = json.dumps(
        payload,
        ensure_ascii=False,
        separators=(",", ":"),
        sort_keys=True,
        allow_nan=False,
    )
    return text.encode("utf-8")
```

```python
# Previously — append-only Wissensspeicher für Projektverläufe
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Hashes für Nutzlast und Event (§3.1 des 1a-Specs).

Der Event-Hash geht über ein **kanonisiertes Objekt**, nicht über eine
Verkettung der Felder: Verkettung ist mehrdeutig, weil `"ab"+"c"` und
`"a"+"bc"` denselben Bytestrom ergeben. `v` und `domain` trennen den
Bereich ab und machen einen künftigen Formatwechsel zu einer
Versionserhöhung statt zu einem stillen Bruch.

Die Nutzlast selbst geht als **Hash** ein, nicht als Inhalt — das ist die
Tilgungs-Naht: wird `payload` zum Grabstein, bleibt der Event-Hash gültig.
"""

import hashlib
from collections.abc import Mapping
from datetime import UTC, datetime

from previously.core.canonical import canonical
from previously.core.errors import InvalidPayload


HASH_VERSION = 1
HASH_DOMAIN = "previously/event"


def iso_utc(moment: datetime) -> str:
    """Kanonische Zeitstempelform: UTC, sechs Nachkommastellen, `Z`."""
    if moment.tzinfo is None or moment.tzinfo.utcoffset(moment) is None:
        raise InvalidPayload(
            "Zeitstempel ohne Zeitzone — Ortszeit wäre nicht reproduzierbar"
        )
    return moment.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%S.%f") + "Z"


def payload_hash(payload: Mapping[str, object]) -> bytes:
    return hashlib.sha256(canonical(payload)).digest()


def event_hash(
    *,
    event_id: int,
    kind: str,
    recorded_at: datetime,
    occurred_at: datetime,
    prev_hash: bytes | None,
    payload_digest: bytes,
) -> bytes:
    kopf: Mapping[str, object] = {
        "v": HASH_VERSION,
        "domain": HASH_DOMAIN,
        "id": event_id,
        "kind": kind,
        "recorded_at": iso_utc(recorded_at),
        "occurred_at": iso_utc(occurred_at),
        "prev": prev_hash.hex() if prev_hash is not None else None,
        "payload": payload_digest.hex(),
    }
    return hashlib.sha256(canonical(kopf)).digest()
```

```python
"""Mechanische Zerlegung von Inhalten in Einheiten (§6 des 1a-Specs).

Mechanisch und deterministisch, nicht interpretierend: keine Spracherkennung,
keine Zuordnung, keine Klassifikation. Das sind Feststellungen und kommen
später.

Weitere Medien bringen ihre eigene, dokumentierte Regel mit.
"""

import re

from previously.contract.types import RawUnit
from previously.core.errors import InvalidPayload


_TRENNER = re.compile(r"\n[ \t]*\n[\s]*")


def split_plaintext(text: str) -> tuple[RawUnit, ...]:
    """Reiner Text: an Leerzeilen trennen, Rand entfernen, ab 1 nummerieren."""
    teile = (teil.strip() for teil in _TRENNER.split(text))
    einheiten = tuple(
        RawUnit(seq=i, content=teil) for i, teil in enumerate((t for t in teile if t), 1)
    )
    if not einheiten:
        raise InvalidPayload("Eingabe ergibt keine Einheiten — leer oder nur Leerraum")
    return einheiten
```

```python
# Previously — append-only Wissensspeicher für Projektverläufe
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Die Storage-Schnittstelle gegen PostgreSQL.

Absichtlich schmal (§5 der Architektur): kein Update, kein Delete, keine
Transaktionssteuerung nach außen, kein SQL-Durchlass, keine Rückgabe von
Datenbankobjekten.
"""

from collections.abc import Iterator, Sequence
from contextlib import AbstractContextManager

from sqlalchemy import Connection, Engine, insert, select

from previously.storage.rows import EventRow, Tip, UnitRow
from previously.storage.schema import event, source_key, unit


class PostgresStorage:
    def __init__(self, engine: Engine) -> None:
        # READ COMMITTED ausdrücklich: das Anfügeverfahren beruht darauf, dass
        # die Unique-Indizes serialisieren. Unter SERIALIZABLE käme stattdessen
        # ein Serialisierungsfehler — eine andere Fehlerklasse.
        self._engine = engine.execution_options(isolation_level="READ COMMITTED")

    def begin(self) -> AbstractContextManager[Connection]:
        return self._engine.begin()

    def tip(self, conn: Connection) -> Tip | None:
        """Spitze der Kette. Beide Werte aus einem SELECT, nie aus zwei."""
        zeile = conn.execute(
            select(event.c.id, event.c.hash).order_by(event.c.id.desc()).limit(1)
        ).one_or_none()
        return None if zeile is None else Tip(id=zeile.id, hash=zeile.hash)

    def lookup(self, conn: Connection, source: str, external_id: str) -> int | None:
        return conn.execute(
            select(source_key.c.event_id).where(
                source_key.c.source == source,
                source_key.c.external_id == external_id,
            )
        ).scalar_one_or_none()

    def insert_event(
        self,
        conn: Connection,
        row: EventRow,
        units: Sequence[UnitRow],
        key: tuple[str, str] | None,
    ) -> None:
        conn.execute(
            insert(event).values(
                id=row.id,
                kind=row.kind,
                recorded_at=row.recorded_at,
                occurred_at=row.occurred_at,
                prev_hash=row.prev_hash,
                hash=row.hash,
                payload_hash=row.payload_hash,
                payload=row.payload,
            )
        )
        if units:
            conn.execute(
                insert(unit),
                [
                    {
                        "event_id": u.event_id,
                        "seq": u.seq,
                        "content": u.content,
                        "start_ms": u.start_ms,
                        "end_ms": u.end_ms,
                        "speaker": u.speaker,
                    }
                    for u in units
                ],
            )
        if key is not None:
            quelle, fremd_id = key
            conn.execute(
                insert(source_key).values(
                    source=quelle, external_id=fremd_id, event_id=row.id
                )
            )

    def read(self, from_id: int, limit: int) -> Iterator[EventRow]:
        """Serverseitiger Cursor: materialisiert nichts."""
        abfrage = (
            select(event)
            .where(event.c.id >= from_id)
            .order_by(event.c.id)
            .limit(limit)
            .execution_options(stream_results=True, yield_per=100)
        )
        with self._engine.connect() as conn:
            for zeile in conn.execute(abfrage):
                yield EventRow(
                    id=zeile.id,
                    kind=zeile.kind,
                    recorded_at=zeile.recorded_at,
                    occurred_at=zeile.occurred_at,
                    prev_hash=zeile.prev_hash,
                    hash=zeile.hash,
                    payload_hash=zeile.payload_hash,
                    payload=zeile.payload,
                )

    def units(self, event_id: int) -> list[UnitRow]:
        with self._engine.connect() as conn:
            return [
                UnitRow(
                    event_id=z.event_id,
                    seq=z.seq,
                    content=z.content,
                    start_ms=z.start_ms,
                    end_ms=z.end_ms,
                    speaker=z.speaker,
                )
                for z in conn.execute(
                    select(unit).where(unit.c.event_id == event_id).order_by(unit.c.seq)
                )
            ]
```

```python
# Previously — append-only Wissensspeicher für Projektverläufe
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Anfügen an das Log (§4 des 1a-Specs).

Die Serialisierung machen ausschließlich die Unique-Indizes auf `prev_hash`
und `id`. Kein Advisory Lock, kein `SELECT … FOR UPDATE`, keine Koordination
zwischen Prozessen — der Verlierer wiederholt.

Drei Konfliktklassen, zwei Wiederherstellungen:

- `event_prev_hash_idx` und `event_pkey` sind **derselbe Vorfall**: zwei
  Schreiber haben aus derselben Spitze dieselbe `id` und dasselbe `prev_hash`
  berechnet. Welcher Index zuerst anschlägt, ist unbestimmt. Spitze neu lesen,
  wiederholen.
- `source_key_pkey` ist **Idempotenz im Rennen**: das Quellereignis existiert
  schon. `lookup` neu lesen, dessen Kennung zurückgeben — nicht wiederholen.
"""

from collections.abc import Sequence
from datetime import datetime
from typing import TYPE_CHECKING

from previously.contract.types import RawEvent
from previously.core.errors import BatchTooLarge, ChainConflict
from previously.core.hashing import event_hash, iso_utc, payload_hash
from previously.storage.rows import EventRow, UnitRow

if TYPE_CHECKING:  # pragma: no cover
    from previously.storage.postgres import PostgresStorage


MAX_RETRIES = 8

# Begrenzte Stapelgröße gegen Verhungern (§4.4 des 1a-Specs): eine sehr große
# Transaktion hält lange und verliert den Konflikt gegen jeden kleinen Einwurf,
# der währenddessen committet.
MAX_BATCH = 500

_KETTENKONFLIKT = ("event_prev_hash_idx", "event_pkey")
_IDEMPOTENZKONFLIKT = ("source_key_pkey",)


def _verletzter_index(fehler: BaseException) -> str | None:
    """Namen des verletzten Unique-Index aus der Treiberausnahme ziehen."""
    beschreibung = str(getattr(fehler, "orig", fehler))
    for name in (*_KETTENKONFLIKT, *_IDEMPOTENZKONFLIKT):
        if name in beschreibung:
            return name
    return None


def append(
    storage: "PostgresStorage",
    events: Sequence[RawEvent],
    *,
    recorded_at: datetime,
) -> list[int]:
    """Fügt Events als Unterkette an und liefert ihre Kennungen.

    `recorded_at` ist **Eingabe, nicht Erzeugnis**: es geht in den Hash ein und
    muss über Wiederholungen stabil bleiben, sonst ist der Hash nicht
    reproduzierbar.
    """
    if len(events) > MAX_BATCH:
        raise BatchTooLarge(
            f"{len(events)} Events in einer Transaktion, erlaubt sind {MAX_BATCH} — "
            "größere Stapel verhungern gegen kleine Einwürfe"
        )
    iso_utc(recorded_at)  # früh scheitern, wenn naiv
    for ereignis in events:
        iso_utc(ereignis.occurred_at)

    from sqlalchemy.exc import IntegrityError  # noqa: PLC0415  # Grenze: nur hier

    for _versuch in range(MAX_RETRIES):
        try:
            with storage.begin() as conn:
                ids: list[int] = []
                spitze = storage.tip(conn)
                naechste_id = 1 if spitze is None else spitze.id + 1
                vorgaenger = None if spitze is None else spitze.hash

                for ereignis in events:
                    vorhanden = storage.lookup(
                        conn, ereignis.source, ereignis.external_id
                    )
                    if vorhanden is not None:
                        ids.append(vorhanden)
                        continue

                    nutzlast_hash = payload_hash(ereignis.payload)
                    dieser_hash = event_hash(
                        event_id=naechste_id,
                        kind="observation",
                        recorded_at=recorded_at,
                        occurred_at=ereignis.occurred_at,
                        prev_hash=vorgaenger,
                        payload_digest=nutzlast_hash,
                    )
                    storage.insert_event(
                        conn,
                        EventRow(
                            id=naechste_id,
                            kind="observation",
                            recorded_at=recorded_at,
                            occurred_at=ereignis.occurred_at,
                            prev_hash=vorgaenger,
                            hash=dieser_hash,
                            payload_hash=nutzlast_hash,
                            payload=ereignis.payload,
                        ),
                        [
                            UnitRow(
                                event_id=naechste_id,
                                seq=u.seq,
                                content=u.content,
                                start_ms=u.start_ms,
                                end_ms=u.end_ms,
                                speaker=u.speaker,
                            )
                            for u in ereignis.units
                        ],
                        (ereignis.source, ereignis.external_id),
                    )
                    ids.append(naechste_id)
                    vorgaenger = dieser_hash
                    naechste_id += 1
                return ids

        except IntegrityError as fehler:
            index = _verletzter_index(fehler)
            if index in _IDEMPOTENZKONFLIKT:
                # Idempotenz hat im Rennen zugeschlagen: nicht wiederholen,
                # sondern die vorhandenen Kennungen zurückgeben.
                with storage.begin() as conn:
                    nachgelesen = [
                        storage.lookup(conn, e.source, e.external_id) for e in events
                    ]
                if all(i is not None for i in nachgelesen):
                    return [i for i in nachgelesen if i is not None]
                continue
            if index in _KETTENKONFLIKT:
                continue  # Spitze neu lesen, erneut versuchen
            raise

    raise ChainConflict(
        f"Kettenposition nach {MAX_RETRIES} Versuchen nicht erlangt — "
        "bei dauerhafter Konkurrenz wäre die Antwort ein einziger "
        "Anfüge-Prozess, keine Sperre"
    )
```

```python
# Previously — append-only Wissensspeicher für Projektverläufe
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Kettenprüfung (§3.4 des 1a-Specs).

Die Prüfung in `id`-Reihenfolge ist zulässig, weil die `id` vom Vorgänger
kommt und nicht aus einer Sequenz: damit ist `id`-Reihenfolge gleich
Kettenreihenfolge, konstruktiv. Deshalb bleibt die Prüfung ein sequenzieller
Scan statt eines Kettenlaufs über Millionen Einzelzugriffe.

Lücken werden nicht gesondert geprüft: eine fehlende Zeile bricht die
Hash-Verlinkung ohnehin, und zweimal dasselbe zu prüfen wäre redundant.
"""

from dataclasses import dataclass
from typing import TYPE_CHECKING

from previously.core.hashing import event_hash, payload_hash

if TYPE_CHECKING:  # pragma: no cover
    from previously.storage.postgres import PostgresStorage


@dataclass(frozen=True)
class Finding:
    event_id: int
    reason: str


def verify(storage: "PostgresStorage", *, batch: int = 1000) -> list[Finding]:
    befunde: list[Finding] = []
    vorheriger_hash: bytes | None = None
    naechste_id = 1
    erwartet_erstes = True

    while True:
        zeilen = list(storage.read(from_id=naechste_id, limit=batch))
        if not zeilen:
            return befunde

        for zeile in zeilen:
            if erwartet_erstes:
                if zeile.prev_hash is not None:
                    befunde.append(
                        Finding(zeile.id, "erstes Event hat prev_hash, erwartet NULL")
                    )
                erwartet_erstes = False
            elif zeile.prev_hash != vorheriger_hash:
                befunde.append(
                    Finding(zeile.id, "prev_hash passt nicht zum Vorgänger")
                )

            if zeile.payload is not None:
                if payload_hash(zeile.payload) != zeile.payload_hash:
                    befunde.append(
                        Finding(zeile.id, "payload_hash passt nicht zur Nutzlast")
                    )

            erwartet = event_hash(
                event_id=zeile.id,
                kind=zeile.kind,
                recorded_at=zeile.recorded_at,
                occurred_at=zeile.occurred_at,
                prev_hash=zeile.prev_hash,
                payload_digest=zeile.payload_hash,
            )
            if erwartet != zeile.hash:
                befunde.append(Finding(zeile.id, "hash passt nicht zu den Feldern"))

            vorheriger_hash = zeile.hash
            naechste_id = zeile.id + 1
```

```python
# Copyright (C) 2026 Jens W. Klein
# SPDX-License-Identifier: AGPL-3.0-or-later
"""Minimaler Einwurfweg (§9 des 1a-Specs).

Nicht als Produktoberfläche gedacht, sondern damit Stufe 1a **läuft** — nicht
weil das nützlich ist, sondern weil Lauffähigkeit Dinge hervortreibt, die man
sonst vergisst.

import argparse
import os
import sys
from collections.abc import Sequence
from datetime import UTC, datetime

from previously.contract.types import Evidence, RawEvent
from previously.core.append import append
from previously.core.errors import InvalidPayload, PreviouslyError
from previously.core.units import split_plaintext
from previously.core.verify import verify
from previously.storage.postgres import PostgresStorage


MAX_TEXT_BYTES = 1_000_000


def parse_moment(text: str) -> datetime:
    """ISO-8601-Zeitstempel **mit** Zone. Ohne Zone wäre Ortszeit gemeint."""
    try:
        moment = datetime.fromisoformat(text)
    except ValueError as fehler:
        raise InvalidPayload(f"{text!r} ist kein ISO 8601-Zeitstempel") from fehler
    if moment.tzinfo is None:
        raise InvalidPayload(
            f"{text!r} hat keine Zeitzone — ohne Zone wäre Ortszeit gemeint und "
            "der Hash nicht reproduzierbar"
        )
    return moment


def _speicher() -> PostgresStorage:
    from sqlalchemy import create_engine  # noqa: PLC0415  # Grenze: nur hier

    dsn = os.environ.get("PREVIOUSLY_DSN")
    if not dsn:
        raise PreviouslyError("PREVIOUSLY_DSN ist nicht gesetzt")
    return PostgresStorage(create_engine(dsn))


def main(argv: Sequence[str] | None = None) -> int:
    zerleger = argparse.ArgumentParser(prog="previously")
    unter = zerleger.add_subparsers(dest="befehl", required=True)

    p_append = unter.add_parser("append", help="Text einwerfen")
    p_append.add_argument("--source", required=True)
    p_append.add_argument("--external-id", required=True)
    p_append.add_argument("--text", required=True)
    p_append.add_argument("--occurred-at")

    p_log = unter.add_parser("log", help="Chronik ausgeben")
    p_log.add_argument("--from", dest="von", type=int, default=1)
    p_log.add_argument("--limit", type=int, default=50)

    unter.add_parser("verify", help="Kette prüfen")

    p_show = unter.add_parser("show", help="Ein Event mit Einheiten zeigen")
    p_show.add_argument("event_id", type=int)

    args = zerleger.parse_args(argv)

    try:
        if args.befehl == "append":
            if len(args.text.encode("utf-8")) > MAX_TEXT_BYTES:
                raise InvalidPayload(
                    f"Text größer als {MAX_TEXT_BYTES} Byte — in kleinere "
                    "Einwürfe teilen"
                )
            geschehen = (
                parse_moment(args.occurred_at)
                if args.occurred_at
                else datetime.now(UTC)
            )
            ereignis = RawEvent(
                source=args.source,
                external_id=args.external_id,
                occurred_at=geschehen,
                evidence=Evidence.RECOLLECTION,
                units=split_plaintext(args.text),
                payload={"text": args.text},
            )
            ids = append(_speicher(), [ereignis], recorded_at=datetime.now(UTC))
            print(ids[0])  # noqa: T201
            return 0

        if args.befehl == "log":
            for zeile in _speicher().read(from_id=args.von, limit=args.limit):
                print(  # noqa: T201
                    f"{zeile.id}\t{zeile.occurred_at.isoformat()}\t"
                    f"{zeile.kind}\t{zeile.hash.hex()[:12]}"
                )
            return 0

        if args.befehl == "verify":
            befunde = verify(_speicher())
            for befund in befunde:
                print(f"BEFUND {befund.event_id}: {befund.reason}")  # noqa: T201
            if not befunde:
                print("Kette intakt")  # noqa: T201
            return 1 if befunde else 0

        if args.befehl == "show":
            speicher = _speicher()
            for zeile in speicher.read(from_id=args.event_id, limit=1):
                if zeile.id != args.event_id:
                    break
                print(f"id={zeile.id} kind={zeile.kind}")  # noqa: T201
                print(f"occurred_at={zeile.occurred_at.isoformat()}")  # noqa: T201
                print(f"hash={zeile.hash.hex()}")  # noqa: T201
                for einheit in speicher.units(zeile.id):
                    print(f"  ¶{einheit.seq} {einheit.content}")  # noqa: T201
                return 0
            print(f"Kein Event {args.event_id}", file=sys.stderr)  # noqa: T201
            return 1

    except PreviouslyError as fehler:
        print(f"Fehler: {fehler}", file=sys.stderr)  # noqa: T201
        return 2

    return 2
```
